功能特性

为开发者打造的完整工具链

从文件编辑到安全部署，GitShip 覆盖代码管理的每个环节

在线文件编辑

直接在浏览器中编辑、新建、重命名、删除仓库文件，无需克隆到本地，改动即时提交。

多仓库管理

同时管理多个 GitHub 仓库，独立设置分支与目标目录，灵活适配不同项目。

批量上传

ZIP / TAR / GZ 一键解压上传，自动初始化空仓库，单次可处理上千文件。

安全加密

GitHub Token 使用 AES-256-GCM 加密存储，密码经 bcrypt 哈希，凭证绝不泄露。

定时任务

配置 Cron 定时自动推送更新，无人值守也能按计划部署，支持启用/暂停。

团队协作

多人共享仓库管理，创建团队、邀请成员共同维护项目，协作效率倍增。

使用流程

三步完成部署

简单三步，告别繁琐的 Git 命令行

1

添加仓库

填写 GitHub 仓库地址和 Token，选择分支与目标目录，一键完成绑定。

2

上传文件

选择 ZIP 压缩包，或使用在线编辑器直接修改文件内容。

3

一键部署

自动解压推送，生成 Commit，部署即时完成。
